## Відомості про предмет

*__Об'єктно-орієнтоване програмування__* — це курс про те, як будувати програми з об'єктів, які вміють зберігати стан, виконувати дії та взаємодіяти між собою.

### Що опануємо

* створення класів та об'єктів у Python;
- атрибути, методи, властивості, `classmethod` і `staticmethod`;
+ інкапсуляцію, наслідування, поліморфізм та абстракцію;
- роботу з Jupyter Notebook і Python-скриптами;
- віртуальні середовища та залежності проєкту;
- оформлення, публікацію і захист результатів у GitHub.

**Головний принцип курсу:** спочатку розібратися, потім реалізувати, а вже потім урочисто сказати: «У мене працює». 😄

Методичні матеріали та повний каталог робіт: [it_college/notes](https://github.com/BobasB/it_college/tree/main/notes).

## Вимоги для виконання лабораторних робіт

1. Створюйте окрему папку або файл для кожної роботи та дотримуйтеся зрозумілої структури.
1. Код має запускатися без помилок, а результати виконання повинні бути видимими у скрипті або Notebook.
1. Для кожного завдання виконуйте всі обов'язкові пункти та індивідуальні завдання, позначені ⭐.
1. Додавайте короткі пояснення до нетривіальних рішень і називайте змінні зрозуміло.
1. Додавайте скріншоти результатів виконання завдань у Notebook або звіті.
1. Перед здачею перевірте роботу локально, збережіть зміни та завантажте їх у GitHub.
1. Надішліть URL репозиторію або потрібної роботи у Google Classroom.

### Маршрут проходження

```text
Клас та об'єкт -> Практика у Notebook -> Парадигми ООП -> Ізольоване середовище
	   |                |                    |                    |
	створюємо       експериментуємо      моделюємо гру        запускаємо стабільно
```

> Одна лабораторна — один крок від «я бачив цей код» до «я можу пояснити цей код».
