### Пракикуємось з вставкою коду

1. Вставка коду у рядок: `print("Hello, world!")`.
1. Вставка коду у блок:
    ```
    Це буде кодовий блок, який можна вставити у текст.
    ```
1. Вставка коду у блок з підсвіткою синтаксису:
    ```python
    print("Hello, world!")
    ```
    ```html
    <h1>Hello, world!</h1>
    ```
